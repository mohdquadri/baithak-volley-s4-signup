# Baithak Volley Dallas Tournament Season 4

Public signup page. Players do not see the roster.

## Share this page

Repo: https://github.com/mohdquadri/baithak-volley-s4-signup

Turn on GitHub Pages:
1. Open the repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **root**
4. Save

Live URL after Pages is on:
https://mohdquadri.github.io/baithak-volley-s4-signup/

## Capture signups + email

The page will not save responses until you paste your Google Apps Script web app URL into `index.html` as `SHEET_WEB_APP_URL`.

That script writes to your private Google Sheet and emails the player.
